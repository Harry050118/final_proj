**VLM-based Mobile GUI Agents.** Vision-language models have driven progress in mobile GUI automation. CogAgent [1] introduced a specialized VLM with dual-resolution encoders for GUI understanding and navigation. SeeClick [2] advanced GUI grounding by pretraining LVLMs on cross-platform screenshot-to-element localization, showing grounding accuracy directly correlates with downstream task success. OS-ATLAS [3] scaled this to a foundation action model trained on 13M+ GUI elements across platforms with strong zero-shot generalization. UI-TARS [4] unified perception, reasoning, and action into a native agent with iterative self-improvement. Falcon-UI [5] proposed decoupled pretraining on instruction-free GUI interaction patterns. While these models excel at action prediction and visual grounding, they do not explicitly optimize the quality of intermediate reasoning steps.

**Chain-of-Thought Reasoning for GUI Tasks.** Structured reasoning has become essential for GUI agents. The Chain-of-Action-Thought (CoaT) paradigm [6] decomposes each action into a multi-step thinking process—description, action-thought, action-decision, and grounding—yielding significant gains over standard prompting on mobile benchmarks. Early work with closed-source models demonstrated GPT-4V performing zero-shot smartphone navigation via screenshot reasoning [7]. However, supervised fine-tuning on CoaT trajectories leads to overfitting to fixed reasoning patterns, and recent studies indicate that chain-of-thought reasoning does not universally benefit mobile GUI agents, with effectiveness varying by model and task [8]. These findings motivate methods that diversify reasoning while preserving correctness.

**Tree Search and Preference Optimization for Reasoning.** To improve reasoning beyond SFT, several methods leverage Monte Carlo Tree Search (MCTS) and preference optimization. ReST-MCTS* [9] uses process reward guided tree search to generate training traces, inferring per-step rewards from oracle final answers. Step-DPO [10] treats individual reasoning steps as preference units for long-chain tasks. Segment Policy Optimization (SPO) [11] partitions sequences into segments for mid-grained credit assignment, while TreeRL [12] integrates on-policy tree search for process-level supervision without a separate reward model. These approaches, however, either require training a process reward model, introduce computational overhead from segment partitioning, or are designed for text-only domains without visual grounding constraints.

**Preference Optimization for GUI Agents.** Recent work has applied RL and preference optimization to GUI agent training. UI-R1 [13] introduces rule-based RL with composite action rewards via GRPO, achieving strong data efficiency on GUI grounding. Mobile-R1 [14] extends this to multi-turn trajectories with task-level rewards for interactive error correction. ReachAgent [15] employs DPO with a four-level reward function to compare action quality across navigation and operation subtasks. TCPO [16] optimizes intermediate reasoning steps through thought-centric preference alignment, enforcing action-policy consistency. However, these methods optimize at the action or task level without jointly refining the CoaT reasoning structure, and lack mechanisms to prevent overfitting during warm-up training. The proposed approach addresses these gaps by constructing thinking-level DPO pairs from a CoaT-tree with rule-based rewards, eliminating the need for process reward models while jointly optimizing reasoning and actions, complemented by instruction evolution to diversify the reasoning space.
