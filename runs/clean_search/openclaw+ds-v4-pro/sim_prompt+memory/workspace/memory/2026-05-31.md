## Problems Encountered

### 1. DeepXiv API Authentication (major time sink)
- Token from .env (`DEEPXIV_API_TOKEN`) was rejected by direct API calls with 401
- Spent ~40 minutes trying every possible auth method (Bearer, Basic, headers, body, cookies, query params, subdomains)
- Key lesson: The token works through the `deepxiv-sdk` Python package, NOT through direct HTTP calls
- Discovered this by reading `rw_eval/external/deepxiv.py` which imports `deepxiv_sdk`
- `pip install deepxiv-sdk` solved the problem immediately

### 2. Hallucinated Reference (1 paper)
- Reference [4] "Transforming Science with Large Language Models" flagged as `metadata_mismatch`
- The title I wrote didn't match what DeepXiv returned exactly
- Lesson: Always verify exact titles/metadata from DeepXiv, don't rely on search-result titles

### 3. Overclaims (4 instances, all mild)
- Claimed Self-Rewarding LMs [10] explore "self-play" — paper uses "self-rewarding" not "self-play"
- Claimed RewardBench [15] established that trained RMs "consistently outperform" general LLM judges — this is an inference, not the paper's central finding
- Claimed surveys [4, 18] "documented this transition from passive to active tools" — neither explicitly documents a historical transition
- Lesson: Don't overstate what papers support. Cite what they actually say, not what you infer.

### 4. Topic Structure Issues
- Preference Optimization paragraph (S2) was judged tangentially related to core theme
- AI-Generated Text Detection paragraph (S4) was judged loosely connected
- The ground truth RW has 3 themes (LLMs for Research, LLMs for Science Discovery, Automated Evaluation); I added Preference Optimization and Text Detection which diluted focus

## Key Lessons for Future Related Work Tasks

1. **Use `deepxiv-sdk` package, not direct HTTP** — saves enormous time
2. **Verify exact titles/metadata** from DeepXiv brief() before writing reference entries
3. **Don't overclaim** — state only what papers explicitly support, not inferences
4. **Stay closer to ground truth themes** — the paper's own RW has 3 themes; adding tangential themes (Preference Optimization, Text Detection) diluted the focus
5. **Cover the "narrative arc"** — not just cite papers, but discuss limitations of prior approaches and how this work addresses them (e.g., "prompt-based methods fail to generate diverse ideas")
6. **Search more broadly** — missed important papers like ResearchAgent, SciMON, MLAgentBench, MARG, Generative Verifiers because queries were too focused on high-level themes
7. **Include historical/classical references** where appropriate — the ground truth cites Langley 1987, Buchanan 1981, LeCun 2015
