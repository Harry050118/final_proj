**MLLMs and LLMs as Evaluators.** The paradigm of using large language models as evaluative judges has gained significant traction with LLM-as-a-Judge frameworks for benchmarking model outputs [1]. However, LLM evaluators exhibit systematic biases, including self-preference—where models favor their own generations [2]—as well as positional and phrasing dependencies that distort evaluation outcomes. Extending evaluative capabilities to multimodal agent settings, vision-language model-based verifiers have been employed to assess and filter web agent trajectories for autonomous refinement [3], while dedicated benchmarks such as AgentRewardBench provide systematic evaluation of LLM judge quality on agent trajectories [4]. Concurrent efforts have explored principled verifier design for computer use agents, emphasizing rubric construction, process-outcome reward separation, and context management [5].

**AI Agents and Self-Improvement.** Interactive agent research has produced realistic benchmarks spanning web navigation [6, 7], computer use [8], and robot manipulation [9]. Self-improvement frameworks such as Reflexion [10] enable agents to reflect on past trajectories using verifier feedback. Evaluator-guided methods have expanded the scope of agent refinement: tree search over action spaces employs model-based value functions to guide exploration [11], agent workflow memory generates prompts and tools from filtered successful trajectories [12], and reinforcement learning with VLM-based rewards has been applied to train device-control agents [13].

**Test-Time Scaling and Reasoning.** The chain-of-thought (CoT) paradigm [14, 15] improves reasoning through intermediate steps, with extensions to multimodal [16] and environment-interaction settings [17] enabling reasoning over visual inputs and agent trajectories. Sampling-based strategies such as self-consistency [18] aggregate multiple reasoning paths via majority voting, while search-based methods explore reasoning trees for deliberate problem solving [19]. Visual grounding techniques like Set-of-Marks prompting [20] enhance MLLMs' ability to process complex visual inputs. In parallel, formal verifiers have been used to select among candidate generations, as demonstrated by process reward models for mathematical reasoning [21] and large reasoning models trained with reinforcement learning from verifier feedback [22]. Extending these test-time scaling and reasoning methods to open-ended interactive settings requires flexible multimodal verification, for which MLLMs offer a compelling foundation—motivating systematic investigation of their capabilities and limitations as verifiers of agent behavior.
