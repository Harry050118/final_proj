**VLM-based Mobile GUI Agents.** Recent advances in vision-language models (VLMs) have driven significant progress in autonomous mobile GUI agents. CogAgent [1] introduced a specialized visual language model for GUI understanding and navigation, leveraging dual-resolution visual encoders to process high-resolution screenshots. SeeClick [2] proposed GUI grounding pre-training to enhance large vision-language models' ability to localize elements on screenshots, enabling cross-platform visual GUI agents. AppAgent [3] demonstrated that multimodal LLMs can operate smartphone apps through human-like interactions via autonomous exploration and demonstration-based learning. Mobile-Agent [4] introduced a vision-centric, system-agnostic agent that uses visual perception to localize operations without relying on structured metadata. Auto-UI [5] proposed a multimodal chain-of-action agent that directly interacts with screen interfaces, bypassing environment parsing and application-specific APIs. Aguvis [6] presented a unified vision-based framework for autonomous GUI interaction operating directly on screen images. Beyond these single-stage models, continual pre-training has emerged as a powerful paradigm: OS-Atlas [7] introduced a foundational GUI action model trained on large-scale synthetic grounding data, achieving strong out-of-distribution generalization. UI-TARS [8] developed a native GUI agent model that operates solely on screenshots, achieving state-of-the-art performance across multiple platforms through large-scale pre-training. DigiRL [9] proposed an autonomous reinforcement learning framework for training device-control agents through online interaction with Android environments. Falcon-UI [10] introduced a decoupled training paradigm that first learns GUI interaction patterns from an instruction-free dataset, then fine-tunes for task following.

**Chain-of-Action-Thought Reasoning for GUI Agents.** To improve decision-making in GUI navigation, several works have explored structured reasoning paradigms. CoAT [11] introduced the Chain-of-Action-Thought prompting paradigm that explicitly models semantic reasoning in GUI navigation by capturing screen context, action thinking, target identification, and outcome prediction, producing the AITZ dataset of high-quality reasoning trajectories. CoCo-Agent [12] proposed comprehensive environment perception and conditional action prediction modules to enrich multimodal perception with historical action context for smartphone GUI automation. InfiGUI-R1 [13] advanced GUI agents from reactive actors to deliberative reasoners through a two-stage Actor2Reasoner framework that injects reasoning capabilities then reinforces them via preference optimization. These works demonstrate that explicit intermediate reasoning improves GUI agent performance, but typically rely on fixed reasoning patterns learned during supervised fine-tuning.

**Self-Training and Preference Optimization for Reasoning.** A parallel line of work addresses the challenge of improving reasoning quality through iterative self-training. ReST-MCTS* [14] proposed a tree-search-based self-training framework that learns a process reward model (PRM) to guide Monte Carlo Tree Search (MCTS) for generating high-quality reasoning traces, though it requires process-level annotations. MCTS-based iterative preference learning [15] demonstrated that MCTS can generate step-level preference signals directly from LLM responses without manual annotation, enabling iterative DPO training. Step-DPO [16] introduced step-wise preference optimization that treats individual reasoning steps as units for preference learning in long-chain mathematical reasoning. Iterative RPO [17] proposed an iterative preference optimization method that generates multiple chain-of-thought paths and uses final-answer correctness to construct training pairs across iterations. CPO [18] leveraged the intrinsic preference structure of tree-of-thought search trees to construct pairwise preferences for fine-grained chain-of-thought optimization. SVPO [19] introduced step-level value preference optimization by using MCTS to generate step-wise preference data for mathematical reasoning. Self-training with DPO [20] combined self-training with direct preference optimization to improve chain-of-thought reasoning in small-scale language models. DeepSeekMath [21] introduced Group Relative Policy Optimization (GRPO), a reinforcement learning approach that uses group-relative advantages for efficient policy optimization in reasoning tasks.

**GUI Datasets and Benchmarks.** The development of mobile GUI agents has been enabled by large-scale datasets. AITW [22] introduced a large-scale real-world Android device-control dataset with 715K episodes spanning diverse tasks and applications. AMEX [23] provided a multi-level annotated dataset with over 104K high-resolution screenshots, featuring complex, long-horizon task instructions. AndroidControl [24] contributed a dataset of human demonstrations with diverse action types, supporting evaluation under both in-distribution and out-of-distribution settings with unseen apps and tasks.
