**Retrieval-Augmented Generation and Agentic RAG.** Retrieval-Augmented Generation (RAG) [1] has become a standard paradigm for grounding large language model (LLM) outputs in external knowledge. Early RAG systems performed a single retrieval step conditioned on the input query, which proved insufficient for complex, multi-hop reasoning tasks [2, 3, 4]. This motivated the development of agentic RAG frameworks, where the LLM is empowered to autonomously issue multiple search queries, incorporate retrieved information, and perform iterative reasoning [5, 6, 7]. In such systems, the model learns to decide when and what to retrieve, opening the door to self-directed knowledge acquisition during step-by-step reasoning. However, this autonomy introduces new challenges: agents may over-search by retrieving information already known from parametric knowledge, or under-search by failing to retrieve when external knowledge is needed.

**Reinforcement Learning for LLM Reasoning.** Reinforcement learning (RL) has emerged as a powerful paradigm for aligning and improving LLM reasoning capabilities. Proximal Policy Optimization (PPO) [8] has been widely adopted for its training stability in complex LLM fine-tuning scenarios. More recently, Group Relative Policy Optimization (GRPO) [9] was proposed as a critic-free alternative that has shown superior sample efficiency for LLM training, albeit with some trade-offs in training stability. These RL algorithms typically rely on outcome-based rewards, where the model receives a single scalar reward based on the correctness of the final answer. While effective for improving answer quality, outcome-based rewards provide no signal about the quality of intermediate reasoning steps, making them ill-suited for optimizing search behavior in agentic RAG.

**RL-Based Search Agents.** Several recent works have applied RL to train LLMs as autonomous search agents. Search-R1 [10] introduced an RL framework that trains LLMs to interleave reasoning with retrieval by generating search queries within structured reasoning traces, using a combination of outcome and format rewards. Building on this, R1-Searcher [11] and its improved version R1-Searcher++ [12] further enhanced the search capabilities of RL-trained agents. The β-GRPO method [13] incorporated length-based or retrieval-count-based penalties into the GRPO objective to encourage shorter reasoning trajectories and reduce redundant search steps. While these methods have demonstrated promising results, they lack fine-grained, step-level supervision on individual search decisions. Length-based penalties can over-suppress retrieval, causing models to avoid search even when necessary, while outcome-only rewards fail to distinguish between optimal and suboptimal search behaviors within a trajectory.

**Process-Level Supervision and Rewards.** The importance of process-level supervision for LLM reasoning has been recognized across multiple domains. In mathematical reasoning, process reward models (PRMs) that evaluate individual reasoning steps have been shown to improve both training and inference-time search [14, 15]. These methods assign a reward or correctness score to each step in a multi-step reasoning chain, providing denser training signals than outcome-only rewards. For retrieval-augmented tasks, some works have explored confidence-based or knowledge-awareness-based rewards to guide search decisions [10, 11]. However, existing approaches typically rely on learned PRMs that may introduce bias, or on heuristic proxies such as confidence scores and knowledge classifiers that imperfectly capture when a search is truly needed. Critically, none of these methods provides explicit, step-specific feedback on each individual retrieval decision, distinguishing whether a particular search was superfluous or whether a missing search should have been taken.

**Prompt-Based Multi-Step Reasoning with Retrieval.** Prior to RL-based approaches, several works achieved multi-step reasoning with retrieval through sophisticated prompting strategies. IRCoT [6] interleaves chain-of-thought reasoning with retrieval by using each reasoning step to generate a query for retrieving relevant passages, then incorporating those passages into subsequent reasoning. Search-o1 [7] extends this paradigm with an agentic framework where the model can issue multiple searches within a single reasoning chain. These prompting-based methods demonstrate that LLMs can effectively leverage retrieval for complex reasoning without additional training, but they lack the ability to learn optimal search policies from experience, and their search behavior is entirely determined by the initial prompt design rather than optimized through training signals.
