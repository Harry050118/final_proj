**Agentic Retrieval-Augmented Generation.** Early work on retrieval-augmented generation (RAG) introduced a retrieve-then-read paradigm in which external knowledge is fetched once and prepended to the model input before generation [1]. While effective for simple factual queries, this single-step approach is often insufficient for complex, multi-hop questions that demand iterative information gathering. To address this limitation, several works have explored interleaving reasoning with retrieval actions. ReAct [2] proposed a prompting framework in which LLMs generate interleaved reasoning traces and actions, enabling dynamic interaction with external knowledge sources such as Wikipedia. IRCoT [3] extended chain-of-thought prompting by interleaving retrieval steps with reasoning sentences, demonstrating substantial improvements on multi-hop QA benchmarks by using retrieved results to guide subsequent reasoning and vice versa. Toolformer [4] took a training-based approach, teaching LLMs to autonomously decide when and how to invoke external tools including search engines through self-supervised learning with a handful of API demonstrations. Self-RAG [5] further advanced this direction by training LLMs to adaptively retrieve passages on demand, generating special reflection tokens that signal retrieval necessity and relevance, thereby making the model controllable during inference. More recently, Search-o1 [6] integrated an agentic search workflow into large reasoning models, introducing a Reason-in-Documents module to refine retrieved information before injecting it into the reasoning chain. These works collectively illustrate the progression from static retrieval pipelines toward autonomous, multi-step search agents; however, they primarily rely on prompting strategies or supervised fine-tuning rather than directly optimizing search behavior through reinforcement learning.

**Reinforcement Learning for Search Agent Training.** Reinforcement learning (RL) has recently emerged as a powerful paradigm for training LLMs to make optimal search decisions during multi-step reasoning. Search-R1 [7] introduced an RL framework that enables LLMs to learn interleaved reasoning and search engine calls using outcome-based rewards, with retrieved token masking to ensure stable optimization. Experiments demonstrated that even base LLMs can develop search and reasoning capabilities solely through RL with outcome rewards. Building on this foundation, R1-Searcher [8] further explored incentivizing search capabilities in LLMs through RL, while its extension R1-Searcher++ [9] focused specifically on improving search efficiency by encouraging dynamic knowledge acquisition and penalizing unnecessary retrievals. AutoSearch [10] addressed the problem of redundant search steps from a different angle, proposing an adaptive search depth framework that uses a self-answering mechanism to identify the minimal sufficient search depth and reward its attainment while penalizing over-search. These RL-based methods represent significant progress toward training efficient search agents, but they share a common limitation: they rely primarily on outcome-based reward functions that evaluate only final answer correctness, lacking fine-grained, step-specific feedback on the quality of individual search and non-search decisions within the reasoning trajectory.

**Process Rewards and Search Efficiency.** The effectiveness of outcome-based rewards for LLM training has been compellingly demonstrated by DeepSeek-R1 [11], which showed that even simple rule-based outcome rewards can elicit complex reasoning behaviors such as self-verification and self-correction when combined with RL algorithms like GRPO [12]. However, in agentic RAG settings, outcome-only rewards provide no direct signal about whether each search step was necessary or whether a missing search led to factual errors. Some prior work has attempted to address this gap by incorporating length-based or retrieval-count penalties to discourage excessive searching, or by integrating model confidence estimates and knowledge-awareness signals into the reward function. Yet these heuristics risk over-suppressing retrieval behavior or rely on imperfect proxies that can misjudge when external knowledge is actually needed. A key gap remains: none of these approaches provides explicit, step-specific feedback on each individual retrieval decision—whether a particular search was superfluous or whether a missing search should have been taken—which is precisely the challenge addressed by the hierarchical process reward framework proposed in this work.
