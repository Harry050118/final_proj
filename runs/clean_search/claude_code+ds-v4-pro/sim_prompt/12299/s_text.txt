**VLM-based Mobile GUI Agents.** Vision-language models (VLMs) have driven significant progress in autonomous mobile device control. CogAgent [1] introduced an 18B-parameter VLM specialized for GUI understanding, using dual-resolution visual encoders to process high-resolution screenshots and achieve strong performance on both GUI grounding and navigation benchmarks. Mobile-Agent [2] leveraged GPT-4V with visual perception tools for autonomous multi-app operations through task planning and self-reflection. AUTO-GUI [3] proposed a multimodal chain-of-action agent that fuses historical action sequences with future action plans for accurate UI interaction without relying on environment parsing. More recently, continual pretraining has emerged as a dominant paradigm: OS-ATLAS [4] introduced a foundation action model that achieves superior GUI grounding through large-scale multi-platform pretraining with consistent action representations. UI-TARS [5] pioneered a native screenshot-only GUI agent trained with enhanced perception and unified action modeling, achieving state-of-the-art performance across diverse GUI benchmarks. Falcon-UI [6] proposed a decoupled training paradigm that first pretrains on diverse GUI interaction patterns before instruction tuning, while UGround [7] introduced universal visual grounding that enables human-like pixel-level GUI interaction across platforms.

**Chain-of-Thought Reasoning for GUI Agents.** Recent work has explored structured reasoning patterns to improve GUI agent decision-making. Android in the Zoo (AITZ) [8] introduced the Chain-of-Action-Thought (CoAT) paradigm, which decomposes each GUI action into a multi-step reasoning process encompassing screen description, action thinking, action decision, and grounding. This thinking–decision–grounding triplet has been validated as an effective reasoning structure for mobile GUI tasks. AUTO-GUI [3] similarly employed a chain-of-action mechanism to connect sequential UI operations. Empirical studies have shown that chain-of-thought reasoning can improve performance in interactive GUI environments, though its benefits on static benchmarks remain mixed [9]. Despite these advances, most existing approaches rely on supervised fine-tuning over fixed CoAT trajectories, which can lead to overfitting and limited reasoning diversity.

**Self-Training via Preference Optimization for Reasoning.** In the general reasoning domain, Direct Preference Optimization (DPO) [10] established a framework for aligning language models with human preferences without explicit reward modeling. Building on DPO, self-training approaches have been developed to iteratively improve reasoning capabilities. Monte Carlo Tree Search (MCTS) has been combined with iterative preference learning to generate step-level preference signals for fine-grained policy updates [11]. ReST-MCTS* [12] proposed process reward guided tree search for LLM self-training, using MCTS to automatically generate reasoning traces and construct preference data without manual process annotations. Self-training with DPO has been shown to improve chain-of-thought reasoning in mathematical domains [13]. More recently, DeepSeek-R1 [14] demonstrated that large-scale reinforcement learning—specifically Group Relative Policy Optimization (GRPO)—can incentivize sophisticated reasoning capabilities in LLMs, while approaches such as Full-Step-DPO [15] leverage self-supervised step-wise rewards for mathematical reasoning. However, these methods either focus on text-only reasoning tasks or require expensive process-level annotations, making them difficult to apply directly to mobile GUI domains where step-level reward annotation is especially costly.

**Instruction and Data Augmentation Strategies.** Data diversity is critical for training robust GUI agents. WizardLM [16] introduced Evol-Instruct, an LLM-driven evolutionary framework that automatically generates diverse, high-complexity instructions through iterative rewriting operations. In the mobile GUI domain, several large-scale datasets have been constructed to support agent training and evaluation: Android in the Wild (AITW) [17] provides 715K episodes across diverse Android tasks; AMEX [18] offers multi-level annotations including element grounding and functional descriptions for over 104K screenshots; and AndroidControl [19] contributes 15K human demonstrations with both high-level and low-level instructions, enabling evaluation of out-of-distribution generalization. Qwen2-VL [20] serves as a strong vision-language backbone widely adopted in recent GUI agent research. However, existing approaches to enhancing instruction diversity in GUI domains have largely relied on static data augmentation or manual curation, rather than automated evolution strategies grounded in real UI screenshots.
